# Andrew Rendon

The plugin Andrew Rendon installs for a business. It connects Claude to the setup he made for that business:

- Claude reads how the business works before writing for it.
- The jobs he set up run as drafts. Nothing is sent without you.
- When you correct something, it is kept, in your words, and every job follows it.
- When you mention what you did with the drafts (sent them, changed them, binned them), that is kept too. It is how he knows the drafts are good.
- He sees when a job stops running or its result can't be found, and fixes it.

Connecting asks for the one-time setup code he gives you in person.
